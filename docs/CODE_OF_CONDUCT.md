# 贡献者公约（Code of Conduct）

## 我们的承诺

为了营造开放、友好、无骚扰的社区，我们承诺：无论年龄、体型、可见或不可见的残障、族裔、性别认同与表达、经验水平、教育背景、社会经济状况、国籍、外貌、种族、宗教或性取向，参与本项目的每个人都应获得尊重的对待。

## 期望行为

- 使用友好、包容的语言。
- 尊重不同的观点、经验与取舍。
- 给予并接受建设性的反馈。
- 关注对社区最有利的事情，而不是个人得失。
- 对其他社区成员保持同理心。

## 不可接受的行为

- 性化的语言或图像，以及任何形式的性骚扰。
- 挑衅、侮辱、贬损性评论，以及人身或政治攻击。
- 公开或私下骚扰。
- 未经明确许可发布他人的私人信息（真实姓名、地址、邮箱等）。
- 在专业场合中其他合理认定为不当的行为。

## 维护者职责

维护者有责任澄清并执行可接受行为的标准，并会对不当行为采取适当、公平的纠正措施，包括删除、编辑或拒绝不符合本公约的评论、提交、代码、Issue 与其他贡献。

维护者可以临时或永久禁止任何他们认为不当、威胁、冒犯或有害的参与者。

## 适用范围

本公约适用于项目空间（仓库、Issue、Pull Request、讨论区）以及个人在公共场合代表本项目时。

## 报告与处理

如遇骚扰或其他不可接受行为，请通过仓库维护者的 GitHub 联系方式私下报告（不要公开 Issue）。所有投诉都会被及时、公正地审查与处理，维护者有义务尊重报告者的隐私与安全。

处理流程：

1. 确认并记录事件。
2. 评估影响，必要时临时限制相关账号的互动。
3. 与当事人沟通处理结果。
4. 视严重程度采取警告、内容删除、临时或永久封禁。
